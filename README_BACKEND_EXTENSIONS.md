## 📞 Support & Troubleshooting

### Common Issues
- **Endpoints not found** → Check `register_all_endpoints()` called
- **Plugin scan slow** → First scan 5-30s, subsequent calls cached
- **React errors** → Verify file paths, check imports
- **Favorites not saving** → Check `~/.codette/` directory permissions
