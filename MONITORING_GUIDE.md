# ?? Live Monitoring Scripts

## ?? Three Ways to Monitor Your Servers

### 1?? One-Time Check (Quick)
```powershell
.\check-status.ps1
```
- ? Quick snapshot of server status
- ? Option to start live monitoring
- ? Shows what to do if servers are down

---

### 2?? Live Monitor (Simple)
```powershell
.\monitor-live.ps1
```
- ? Continuously checks every 5 seconds
- ? Shows real-time status
- ? Simple text output
- ? Press Ctrl+C to stop

**What it shows:**
- ?? Python DSP Server status
- ? React Frontend status  
- ?? WebSocket connection status
- ?? DSP availability
- ?? Codette AI status

---

### 3?? Dashboard Monitor (Beautiful)
```powershell
.\monitor-dashboard.ps1
```
- ? Beautiful boxed layout
- ? Auto-refresh every 3 seconds
- ? Shows uptime
- ? Color-coded status boxes
- ? Detailed information
- ? Press Ctrl+C to stop

**What it shows:**
- ?? Boxed status displays
- ?? Uptime counter
- ?? Color-coded (Green=Online, Red=Offline)
- ?? Detailed server info
- ?? URLs and ports
- ?? Suggested actions if offline

---

## ?? When to Use Each

| Script | Use Case |
|--------|----------|
| **check-status.ps1** | Quick check before starting work |
| **monitor-live.ps1** | Lightweight monitoring while developing |
| **monitor-dashboard.ps1** | Beautiful dashboard for presentations/demos |

## ?? Typical Workflow

### Starting Your Day:
```powershell
# 1. Check if anything is running
.\check-status.ps1

# 2. Start servers if offline
.\start-safe.ps1

# 3. Open live monitor in separate window
.\monitor-dashboard.ps1
```

### During Development:
- Keep **monitor-dashboard.ps1** running in a separate window
- Glance at it to see real-time server health
- If something goes offline, you'll see it immediately

### Ending Your Day:
```powershell
# Stop the monitor (Ctrl+C)
# Then stop the servers
.\stop-all.ps1
```

### Python DSP Server

| Status | Meaning | Action |
|--------|---------|--------|

| ? OFFLINE | Server not responding | Run `.\start-safe.ps1` |

- **Codette AI: ?** - AI unavailable

| Status | Meaning | Action |
|--------|---------|--------|

## ?? Pro Tips

### Tip 1: Keep Dashboard Open
Run the dashboard in a separate window while developing:
```powershell
Start-Process powershell -ArgumentList "-NoExit", "-Command", ".\monitor-dashboard.ps1"
```

### Tip 2: Quick Check Alias
Add to your PowerShell profile:
```powershell
function Check-DAW { .\check-status.ps1 }
Set-Alias -Name daw-status -Value Check-DAW
```
Then just type: `daw-status`

### Tip 3: Startup Routine
Create a startup script that does everything:
```powershell
# start-and-monitor.ps1
.\start-safe.ps1
Start-Sleep -Seconds 20
Start-Process powershell -ArgumentList "-NoExit", "-Command", ".\monitor-dashboard.ps1"
```

## ?? Troubleshooting

### Monitor Shows "OFFLINE" But Server Window Says "READY"
**Problem:** Port might be blocked or firewall issue  
**Solution:**
```powershell
# Check if port 8000 is listening
netstat -ano | findstr :8000

# If nothing shows, restart the Python server
```

### Monitor Crashes or Freezes
**Problem:** PowerShell execution timeout  
**Solution:**
```powershell
# Stop with Ctrl+C and restart
# Or use the simple monitor instead
.\monitor-live.ps1
```

### "Access Denied" Error
**Problem:** PowerShell execution policy  
**Solution:**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
